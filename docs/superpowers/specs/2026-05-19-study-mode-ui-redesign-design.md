# 学习模式UI重构与字典查询功能设计

## 概述
对五种学习模式进行iOS风格的UI重构，修复测验模式bug，添加答题反馈卡片和快捷字典查询功能。

## 架构设计

### 1. 测验模式Bug修复
- **问题**：模式5（中选英）调用 `_generateCnQuizOptions` 生成中文选项，但应该生成英文单词选项
- **修复**：模式5调用 `_generateQuizOptions` 生成英文单词，模式4调用 `_generateCnQuizOptions` 生成中文释义

### 2. iOS风格UI规范
- **圆角**：卡片20px，按钮12px，输入框10px
- **阴影**：柔和阴影 `BoxShadow(color: Colors.black.withValues(alpha: 0.08), blurRadius: 12, offset: Offset(0, 4))`
- **字体**：标题使用 `FontWeight.w600`，正文使用 `FontWeight.w400`
- **动画曲线**：`Curves.easeOutCubic`（iOS风格弹性动画）
- **动画时长**：卡片弹出300ms，选项切换200ms，页面过渡350ms
- **颜色**：正确=系统绿(#34C759)，错误=系统红(#FF3B30)，主色=系统蓝(#007AFF)

### 3. 答题反馈卡片（底部弹出式）
**组件名**：`_AnswerFeedbackSheet`

**触发时机**：
- 测验模式：选择答案后立即弹出
- 拼写模式：提交答案后弹出
- 听力模式：提交答案后弹出

**卡片结构**：
```
┌─────────────────────────────────┐
│  [状态栏] ✓ 回答正确 / ✗ 错误   │  iOS系统绿/红色背景
├─────────────────────────────────┤
│  正确答案：abandon              │
│  你的答案：abondan（错误时显示）│
├─────────────────────────────────┤
│  abandon /əˈbændən/             │
│  v. 放弃，抛弃                  │
│  [🔊 播放发音]                  │
├─────────────────────────────────┤
│  [→ 下一题]  [✕ 退出]           │  iOS风格按钮
└─────────────────────────────────┘
```

**动画**：
- `showModalBottomSheet` 实现底部弹出
- 背景遮罩淡入（200ms）
- 状态图标弹跳动画（`Curves.elasticOut`）

### 4. 快捷字典查询
**组件名**：`_DictionarySearchSheet`

**入口**：学习界面AppBar右侧添加搜索图标

**交互流程**：
1. 点击搜索图标 → 弹出底部搜索框
2. 输入单词 → 实时搜索（300ms防抖）
3. 显示结果列表 → 点击单词 → 弹出详情卡片
4. 详情卡片显示：单词、音标、释义、例句、发音按钮

**数据来源**：
- 优先：`LocalDictionaryService.lookup()` 本地ECDICT
- 补充：`DictionaryApiService.fetchWord()` 在线API

### 5. 五种模式UI重构要点

#### 回忆模式
- 单词区域：大字体显示，音标在下方，发音按钮在右上角
- 释义区域：点击"显示释义"后使用 `AnimatedCrossFade` 展开
- 评分条：iOS风格分段控制器（Segmented Control）

#### 拼写模式
- 提示区：中文释义居中显示，圆角卡片背景
- 输入区：iOS风格文本框，底部边框，聚焦时变色
- 字符计数：右下角小字显示
- 提交后：显示正确拼写对比动画

#### 听力模式
- 播放按钮：大圆形按钮，播放时脉冲动画（`AnimatedScale`）
- 输入/选择区：根据模式显示输入框或选项
- 重播按钮：小图标按钮在播放按钮下方

#### 测验模式（两种）
- 题目区：渐变背景卡片，大字体显示问题
- 选项区：4个选项卡片，依次淡入动画（`StaggeredAnimation`）
- 选项标签：A/B/C/D圆形标签
- 选中效果：边框变粗+轻微缩放
- 结果反馈：正确=绿色边框+对勾，错误=红色边框+叉号

## 数据流

```
用户操作 → 状态更新 → 显示反馈卡片 → 用户选择下一题/退出
                                    ↓
                            更新复习记录 → 保存数据库
```

## 错误处理
- 字典查询失败：显示"未找到该单词"提示
- 网络异常：降级到本地词典或TTS
- 数据库异常：catch并debugPrint，不影响UI
