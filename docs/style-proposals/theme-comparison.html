主题风格方案对比

保留现有「流体渐变 / 液态玻璃」双风格架构，只对色彩与视觉噪音做精修。下方每个方案都是同一张首页看板，可直接对比按钮可读性、层次与噪音感。

最终决策：保留现状配色（#F093FB → #4FACFE 色板与渐变一个不动）。 对比度问题改用「亮渐变配深色前景」解决：只把渐变之上的文字/图标由白色改为 #1A1A2E， 对比度 2.04:1 → 8.34:1。本页保留作为决策记录，下方 A / B / C 三套换色方案未采用。

三个方案共用的「降噪 + 治理」项

无论选哪个配色，以下工程项都会一并执行。这是本次优化的第二个重点。

① 砍掉常驻动画层

现状同时跑 4 层动画：15s 背景流动 + 每张卡片 3s shimmer + 8s 标题渐变流动 + hover 光流。改为背景 40s 极缓（移动端静止）、shimmer 仅保留「选中/加载中」态、标题改纯色。

常驻动画 4 层 → 1 层

② 玻璃模式降开销

blurSigma 30 → 18；全局光斑由 3 颗降为 2 颗且降低运动幅度；卡片 BackdropFilter 统一加 RepaintBoundary；嵌套玻璃继续走已有的自动降级路径。

全屏模糊开销约降 40%

③ 删除死代码

lib/utils/theme/design_tokens.dart（DesignTokens，仅自引用）与 lib/utils/theme/theme_provider.dart（GlassThemeProvider，在 main.dart:61 注册但全项目零消费点）一并移除，消除两个同名 ThemeProvider 的阅读歧义。

删除 2 个文件 + 1 处注册

④ 间距令牌落地

FluidTheme 已定义 spacingXs~Xxl，但代码中大量 EdgeInsets.all(16) 硬编码。统一替换为令牌，并补齐 spacingLg/sm 之间缺失的 12/20 档。

新增 2 档令牌

⑤ 状态色接入 ColorScheme

success / warning / error / info 目前是 FluidTheme 的静态常量，Material 原生组件取不到。改为写入 ColorScheme 扩展位，并统一为过对比度校验的色值。

4 个状态色

⑥ 启动页配色对齐

启动页当前用浅绿 #F8FBF7，进 App 跳成粉紫，第一印象割裂。改为直接复用主色的极浅变体，让启动 → 主页过渡连续。
